What is Santai?

Campus knowledge that doesn't start over at zero

Where students publish projects, notes, and class or club know-how — so the next person doesn't start from scratch.

  • Publish projects and notes to a public, searchable home
  • Open any project and build on it by chatting with an AI agent
  • No dev environment, no terminal — coder or not
Who It's For

Same base, real value for everyone

Built so a CS senior and a first-year who's never opened a terminal both get something out of it.

If you code

Skip the boring part. Fork a working project instead of scaffolding one. The agent handles setup, edits, and test runs — you review and steer.

If you don't

Describe it, watch it happen. Say what you want in plain English. No install, no CS degree — a live preview shows the result as it's built.

The Problem

Every semester, campus knowledge resets

  • Onboarding docs, reusable class projects, hackathon builds with real potential…
  • …live on one laptop or a group chat that scrolls away when the team graduates
  • Building on someone's project usually means knowing how to code well enough to set it up — shutting out most students before they see if the idea is good
The Product

A public home — and a way to build on it

Publish

Projects and notes get a public page — tagged, categorized, searchable, ready to reuse.

Collaborate

Groups mirror campus teams — class, club, hackathon squad — with shared access and one-click import of Docs, Slides & PDFs.

Build

Open any project in a live chat with an agent that reads, edits, runs it, and shows a live preview.

How It Works

Four steps, none require code

1

Find

Search projects and notes shared by other students, clubs, or teams.

2

Open — nothing to install

It spins up ready to run, in your browser, in its own private sandbox.

3

Tell the agent

Chat like a teammate; watch a live preview update as it writes and runs changes.

4

Publish or hand it in

Save your version back so the next person picks up where you left off.

Why Now

Build by describing — not by knowing how to code

AI agents changed what a non-CS student can ship. Campus is the right place to start.

  • A business or design student can now ship a real class project — not just a CS major
  • Students are the fastest adopters of new AI tools
  • A class project, club, or hackathon is a low-stakes place to try building something you couldn't before
Business Model

Free to browse & publish; pay for building time

  • Every chat session runs on real model calls — billing is metered, not a seat license
  • A credits ledger charges each session for what it uses, priced off live gateway rates so margin holds as models change
  • Student-first: credit packs feel like a streaming subscription — and the same metering carries cleanly to teams & companies
Under the Hood

Already a working platform — not a mockup

  • App — hub.sant.ai: sign-in, public profiles, search & filter across projects and notes
  • Agent — each session runs in its own private sandbox with a real AI coding agent inside
  • Import — Google Docs, Sheets, Slides, PDFs & Markdown pull straight into a knowledge base
  • Billing — Stripe-backed credits, live usage pricing, admin override tooling
  • Publishing — GitHub-backed version history and a built-in deploy pipeline
