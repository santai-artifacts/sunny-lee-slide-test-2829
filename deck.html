Santai Hub

A home for student projects and know-how — with an AI teammate that can actually build.

2

What is Santai?

Santai Hub is where students publish projects, notes, and class or club knowledge — so the next person doesn't start from zero.

  • Publish projects, notes, and shared know-how to a public, searchable home
  • Open any project and build on it by chatting with an AI agent
  • No dev environment, no setup — coder or not
Lead with the core promise — reuse campus knowledge, and let anyone build on it.
3

Who It's For

Built so a CS senior and a first-year who's never opened a terminal get real value from the same base.

  • **If you code** — Skip the boring part. Fork a working project instead of scaffolding from scratch; the agent handles setup, edits, and test runs while you review and steer.
  • **If you don't** — Describe it, watch it happen. Say what you want in plain English; a live preview shows the result as the agent builds it.
4

The Problem

Every semester, campus knowledge starts over at zero.

  • A club's onboarding doc, a reusable class project, a hackathon build with real potential
  • Most of it lives on one laptop or in a group chat that scrolls away when the team graduates
  • Building on someone else's project usually means knowing how to code well enough to set it up — which shuts out most students before they see if the idea is good
5

The Product

A public, searchable home for what students build — plus a way to build on it without needing to code.

  • **Publish** — Projects and notes get a public page: tagged, categorized, searchable, ready to reuse
  • **Collaborate** — Groups mirror how campus teams already work — a class, a club, a hackathon squad — with shared access and one-click import of Docs, Slides, and PDFs
  • **Build** — Open any project in a live chat with an AI agent that reads it, edits it, runs it, and shows a live preview
6

How It Works

Four steps, and none of them require knowing how to code.

  • **1. Find something worth building on** — Search projects and notes shared by other students, clubs, or teams
  • **2. Open it — nothing to install** — It spins up ready to run, in your browser, in its own private sandbox
  • **3. Tell the agent what you want** — Chat like you would with a teammate; watch a live preview update as it writes and runs changes
  • **4. Publish or hand it in** — Save your version back so the next person can pick up where you left off
7

Why Now

AI agents made it possible to build software by describing what you want, not by knowing how to code it.

  • A business or design student can now ship a real class project — not just a CS major
  • Students are the fastest adopters of new AI tools
  • A class project, club, or hackathon is a low-stakes place to build something you couldn't before
Campus is the wedge — fastest adopters, lowest stakes to experiment.
8

Business Model

Free to browse and publish; pay only for the AI's building time.

  • Every chat session runs on real model calls, so billing is metered — not a seat license
  • A credits ledger charges each session for what it actually uses, priced off live model-gateway rates so margin holds as models change
  • Student-first pricing: credit packs feel like a streaming subscription, not an enterprise seat — and the same metering carries cleanly to teams and companies
9

Under the Hood

Early-stage, but already a working platform — not a mockup.

  • **App** — Web app at hub.sant.ai with sign-in, public profiles, and search/filter across projects and notes
  • **Agent** — Each session runs in its own private sandbox with a real AI coding agent inside
  • **Import** — Google Docs, Sheets, Slides, PDFs, and Markdown pull straight into a knowledge base
  • **Billing** — Stripe-backed credits, live usage pricing, admin override tooling
  • **Publishing** — GitHub-backed version history and a built-in deploy pipeline
